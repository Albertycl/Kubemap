## New finding (no change made)

The Calico IP pool `default-ipv4-ippool` is `192.168.0.0/16`, which overlaps the home network `192.168.32.0/24` (k8server and the Windows PC). Pods use only `192.168.41.128/26` today. If Calico ever gives a pod an address in `192.168.32.0/24`, traffic to that pod and to the LAN host with the same address will conflict. Fixing this needs a new IP pool and pod migration, so it is a planned change, not a quick fix.
